# Lab 05 — API тестчлэл

## 1. Төслийн зорилго

Энэхүү лабораторийн ажлын зорилго нь оюутны хичээлд бүртгүүлэх API-г хөгжүүлж, Postman болон Newman ашиглан API-ийн ажиллагааг автомат тестээр шалгах юм.

Тестийн үр дүнг файлд хадгалж, Git ашиглан хувилбарын удирдлага хийсэн.

## 2. Ашигласан технологи

- **Node.js** — API сервер ажиллуулах
- **Postman** — API хүсэлт илгээх, тест бичих
- **Newman** — Postman collection-ийг командын мөрөөс ажиллуулах
- **Git** — Код болон тестийн үр дүнг хувилбарын удирдлагад оруулах
- **PowerShell** — Команд ажиллуулах

## 3. Төслийн бүтэц

```text
lab05-api-testing/
├── server.js
├── package.json
├── lab05-collection.json
├── lab05-collection-fail.json
├── README.md
└── results/
    ├── newman-pass.txt
    ├── newman-fail.txt
    └── newmandown.txt
```

## 4. API сервер ажиллуулах

Эхлээд PowerShell нээгээд төслийн хавтас руу орно.

```powershell
cd "C:\Users\User\lab05-api-testing"
```

API серверийг ажиллуулна.

```powershell
node server.js
```

Сервер ажиллаж байх үед энэ PowerShell цонхыг нээлттэй үлдээнэ. Newman тестийг өөр PowerShell цонхонд ажиллуулна.

Үндсэн хаяг: http://localhost:3000

## 5. API тестүүд

`lab05-collection.json` файлд дараах 9 тохиолдлыг шалгах тестүүд багтсан.

1. Идэвхтэй оюутан хичээлд амжилттай бүртгүүлэх.
2. Идэвхгүй оюутны бүртгэлийг татгалзах.
3. Байхгүй оюутны бүртгэлийг татгалзах.
4. Байхгүй хичээлийн бүртгэлийг татгалзах.
5. Урьдчилсан нөхцөл хангаагүй үед бүртгэлийг татгалзах.
6. `studentID` талбар байхгүй үед хүсэлтийг шалгах.
7. `courseID` талбар байхгүй үед хүсэлтийг шалгах.
8. Урьдчилсан нөхцөлгүй хичээлд бүртгүүлэх.
9. Оюутан болон хичээл хоёулаа байхгүй үеийн алдааг шалгах.

## 6. Амжилттай тест ажиллуулах

API сервер ажиллаж байгаа эсэхийг шалгаад, төслийн хавтас дахь өөр PowerShell цонхонд дараах командыг ажиллуулна.

```powershell
New-Item -ItemType Directory -Force results
newman.cmd run lab05-collection.json 2>&1 | Tee-Object -FilePath results/newman-pass.txt
```

Тестийн үр дүнг `results/newman-pass.txt` файлд хадгална.

### Тестийн үр дүн

- Нийт хүсэлт: 21
- Амжилтгүй хүсэлт: 0
- Assertion: 18
- Амжилтгүй assertion: 0

## 7. Зориуд алдаатай тест ажиллуулах

`lab05-collection-fail.json` файлд зориуд буруу хүлээлт оруулсан тест бий. Ингэснээр API-ийн хариу хүлээлттэй таарахгүй үед тест хэрхэн `FAIL` болохыг харуулна.

```powershell
newman.cmd run lab05-collection-fail.json 2>&1 | Tee-Object -FilePath results/newman-fail.txt
```

Хүлээгдэж буй үр дүн:

- Нэг зориудын assertion `FAIL` болно.
- Бусад тестүүд үр дүнгээ харуулна.
- Тайлан `results/newman-fail.txt` файлд хадгалагдана.

## 8. Сервер ажиллахгүй үеийн тест

API сервер унтарсан үед Newman хүсэлтүүд сервертэй холбогдож чадахгүй тул `ECONNREFUSED` алдаа гарч болно.

Энэ үр дүнг дараах файлд хадгалсан.

```text
results/newmandown.txt
```

Энэ нь сервертэй холбогдох боломжгүй үеийн алдааг харуулна. Сервер унтарсан үед гарсан холболтын алдаа нь API-ийн бүх тест буруу гэсэн үг биш юм.

## 9. Git хувилбарын удирдлага

Өөрчлөлтийн төлөвийг шалгах:

```powershell
git status
```

Файлуудыг Git-д нэмэх:

```powershell
git add README.md lab05-collection.json lab05-collection-fail.json results
```

Commit хийх:

```powershell
git commit -m "Update API testing documentation and results"
```

Commit-уудыг шалгах:

```powershell
git log --oneline
```

GitHub руу илгээх:

```powershell
git push -u origin main
```

Хэрэв GitHub-аас `403 Permission denied` алдаа гарвал репозиторид бичих эрхтэй GitHub бүртгэлээр нэвтэрсэн эсэхээ шалгана.

## 10. Дүгнэлт

Энэхүү лабораторийн ажлаар REST API-ийн үндсэн ажиллагааг шалгаж, Postman collection үүсгэн, Newman ашиглан автомат тест ажиллууллаа.

Амжилттай тест, зориуд алдаатай тест болон сервер ажиллахгүй үеийн үр дүнг тус тусад нь хадгалсан. Мөн Git ашиглан төслийн өөрчлөлт болон тестийн тайлангуудыг хувилбарын удирдлагад оруулсан.

**Анхаарах зүйл:** `newmandown.txt` файл дахь холболтын алдаа нь сервер ажиллаагүй үед үүссэн. Энэ нь API-ийн бүх тест буруу гэсэн үг биш юм.
